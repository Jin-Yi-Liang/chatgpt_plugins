# 对话导航 · ChatGPT

在 ChatGPT 网页右侧添加按用户提问组织的目录，方便浏览长会话，并把选中的模型回复连续复制或导出为 Markdown。

当前版本 **0.6.2**，支持桌面 Chrome / Firefox 的 Tampermonkey。运行网站：`https://chatgpt.com/`、旧域名 `https://chat.openai.com/`。DeepSeek 与 Claude 仅预留代码接口，当前未启用。

## v0.6.2 更新

- 修复回复生成期间手动滚动被拉回原位置：正文及外层页面滚动可立即解除原锚点保持，后续流式更新不会重新锁回。
- 修复空输入框或输入框滚动边界上的接管遗漏；输入框内部仍有可滚动内容时，只滚动草稿，不影响正文保持。
- 提前在窗口捕获阶段识别真实操作，覆盖被网页截断的事件；原生滚动条接管覆盖各层滚动容器。
- 保留“发送后保持阅读位置”的默认行为，以及三级目录、公式复制、自定义/删除和Markdown导出。

## 安装

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/) 安装对应浏览器的官方脚本管理器。
2. Chrome 安装后请确认 Tampermonkey 扩展详情中的“允许用户脚本 / Allow User Scripts”已开启；脚本列表中的“启用”与浏览器执行许可是两项设置。见 [官方说明](https://www.tampermonkey.net/faq.php?q=Q209)。
3. 点击本页“安装此脚本”，在 Tampermonkey 确认页核对名称及站点并安装。
4. 如已安装同项目的原生浏览器扩展，请先停用，避免重复注入。
5. 刷新 ChatGPT，进入已有会话，右侧即显示导航面板。

## 功能

| 操作 | 效果 |
| --- | --- |
| 发送新提示词 | 默认保持原阅读位置；设置中可关闭，正文滚动或导航可接管 |
| 双击公式 | 复制 LaTeX；设置中可切换 Markdown 格式，随后 Ctrl+V 粘贴 |
| 单击提问文字 | 定位到对应提问，页面布局变化时短暂校正 |
| 导航内滚轮 | 浏览完整目录，上下边界不继续带动会话页面 |
| `✎` | 自定义提问导航标题，保存后刷新仍保留；可恢复原提问 |
| `×` | 删除当前导航项，不删除原始对话；没有手动添加入口 |
| `▸` / `▾` | 逐层展开 / 收起该问题回复的 H1 → H2 → H3，各层初始关闭 |
| H1 / H2 / H3 子标题 | 点击定位到模型回复标题，只读，不支持改名和删除 |
| 搜索 / 清空搜索 | 同时匹配原始提问及自定义标题，显示匹配数与筛选外已选回复 |
| 当前提问 | 清空筛选并把目录滚到当前提问，保持会话正文位置 |
| 多选问题 | 按原会话顺序合并对应模型回复，与勾选顺序无关 |
| 复制 Markdown / 导出 .md | 写入剪贴板或下载连续回复，可选择包含提问标题 |
| `⚙` | 切换自动 / 兼容模式与导出设置 |

回复更新和发现更多提问时保留已有导航行，编辑中的标题草稿、光标与勾选不会被重建打断。展开、编辑、删除和面板收放支持键盘焦点衔接。

支持深色主题、窄屏、收起面板和 `Alt + Shift + N` 快捷键；Tampermonkey 菜单中也可“显示 / 收起对话导航”。

## 数据与权限

自定义标题、导航删除状态和界面偏好保存在本机脚本管理器的 GM 存储。扩展版与油猴版、不同浏览器之间独立保存，当前没有自动迁移或云同步。

提问和回复正文在本页内存中用于导航及导出，不由本脚本上传到作者服务器。脚本没有作者遥测、后台服务或 ChatGPT 私有 API 调用。将完整提问主动保存为自定义标题时，该标题会进入本地 GM 存储。

仅申请 `GM_getValue`、`GM_setValue`、`GM_setClipboard`、`GM_registerMenuCommand`。回复复制由用户点击触发，公式复制由用户真实双击触发；不读取剪贴板。下载采用浏览器 Blob，无需 `GM_download`。

主程序完整包含在本文件内。Markdown 转换使用 MIT 许可的 Turndown 7.2.4 与 turndown-plugin-gfm 1.0.2；Tampermonkey 安装 / 更新时从 jsDelivr 获取固定版本的 `@require`，并核对元信息中的 SHA-256。

## 行为与限制

- 长会话会整理已加载的消息窗口，保留暂时离开 DOM 的目录和已读取回复。只探测缺失消息的占位节点，正文完整时不扫描长回复；最多运行 25 秒，手动操作会立即接管并恢复正文显示。随后正常滚动继续补充已发现条目。
- 回复仍在生成或尚无内容时，会提示等待，避免导出不完整内容。
- Markdown 支持代码、表格、链接、图片 URL 和 LaTeX 公式。图片仅保留 URL，临时链接可能过期。
- 公式复制需要网页保留可读取的 LaTeX 或 MathML 源信息；图片和缺失源码的公式无法转成源码，届时会提示且不改写剪贴板。
- 服务端未加载的历史、隐藏分支、复杂图表 / Canvas 内容无法保证完整读取。ChatGPT 页面结构变化可能需要更新。
- 读取回复的一至三级标题；H4～H6 不列入导航，Markdown 导出仍保留原始标题层级。选区与展开状态刷新后重置，标题、删除状态和偏好保留。

本版在真实 Chrome for Testing 156 / Firefox 158 中安装官方 Tampermonkey 5.5.1 / 5.5.0，分别通过 53 组集成测试；原生扩展另有 106 组回归。会话采用模拟数据及脱敏 DOM，并非作者登录 ChatGPT 会话的现场验收。
